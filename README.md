### 🛒 [Basiclike 쇼핑몰](https://github.com/Jengsoi/shopingmall_solo)

C# / .NET 8과 WPF로 만든 데스크톱 쇼핑몰을 **혼자 설계하고 구현한 프로젝트**입니다.

고객은 상품 조회, 장바구니, 주문, 게시판을 이용하고  
관리자는 매출 대시보드와 재고·주문 관리 화면으로 매장을 운영합니다.

- 회원가입 / 로그인 / 내 정보 수정 / 탈퇴
- 상품 검색, 장바구니, 주문 및 주문내역 조회
- 주문 상태 흐름 관리 (결제완료 → 배송준비중 → 배송중 → 배송완료 / 주문취소)
- 주문 취소 시 재고 자동 복구
- 재고 변경 이력 기록 (변동 수량, 변경 전후 재고, 주문번호, 처리자)
- 매출 대시보드 (기간별 매출, TOP 5 막대 차트, 카테고리별 도넛 차트)
- 게시판 글쓰기 / 수정 / 삭제 / 댓글
- 쇼핑몰 · 재고관리 · 대시보드 서버 분리 (TCP 비동기 통신, 줄바꿈 구분 JSON)
- 트랜잭션 기반 주문·재고 처리와 동시 주문 통합 테스트

`C#` `.NET 8` `WPF` `MySQL` `TCP/IP` `async/await` `JSON`
